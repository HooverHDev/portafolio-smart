# Hoover Huaman | Portafolio Smart

Portafolio personal de desarrollo de software diseñado para presentar mi perfil profesional, habilidades técnicas, proyectos y objetivos de crecimiento en el área de desarrollo Backend y servicios en la nube.

## Objetivo

Mostrar mis conocimientos actuales, documentar mi evolución como desarrollador y presentar proyectos que reflejen mi experiencia práctica en desarrollo web, bases de datos y tecnologías de Microsoft Azure.

## Características

- Presentación personal y perfil profesional.
- Sección de habilidades técnicas y tecnologías.
- Presentación de proyectos de desarrollo web.
- Diseño adaptable a diferentes tamaños de pantalla (responsive).
- Navegación entre secciones y enlaces a proyectos.
- Enfoque profesional en Backend y desarrollo de aplicaciones web.
- Organización de tecnologías actuales y áreas de aprendizaje.

## Proyectos destacados

### Derquin Web
Sitio web publicitario para una distribuidora de productos químicos, artículos de limpieza y materiales para obra.

Funciones principales:
- Presentación de productos destacados.
- Catálogo de productos.
- Acceso a fichas técnicas.
- Sección para solicitar cotizaciones.
- Formulario de contacto con el administrador.

Tecnologías: PHP, HTML, CSS y SQLite.

## Estructura general

El proyecto está organizado para separar la página principal, los estilos, los recursos visuales y los elementos necesarios para presentar el portafolio.

La estructura exacta puede variar según la versión del proyecto.

## Ejecución local

1. Descarga o clona el repositorio.
2. Abre la carpeta del proyecto.
3. Abre `index.html` en tu navegador.

Si el proyecto utiliza rutas o recursos que requieren un servidor local, puedes ejecutarlo mediante la extensión Live Server de Visual Studio Code.
